# Carbon Footprint · PNB Digital

Prototipo navegable de la app de huella de carbono (inventario GEI, GHG Protocol e ISO 14064-1). Primer cliente: SENA.

Abrir `index.html` en el navegador o verlo publicado con GitHub Pages.

Prototipo de experiencia: los datos son de referencia y las acciones (guardar, Word, carga de archivos) son simuladas.
